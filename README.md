# 🛍️ Retail Analytics & Customer Segmentation

An end-to-end retail analytics project that combines **Python, SQL Server, and Power BI** to analyze sales performance, customer behavior, product performance, and geographic trends.

The project includes data cleaning, SQL-based business analysis, **RFM customer segmentation**, and an interactive four-page Power BI dashboard.

---

## 📌 Project Overview

The objective of this project is to transform raw retail transaction data into meaningful business insights.

The workflow covers:

- Data cleaning and transformation using Python
- Data storage and analysis using SQL Server
- Customer segmentation using RFM analysis
- Business analysis using SQL
- Interactive dashboard development using Power BI
- DAX-based KPI and metric creation

## 👥 RFM Customer Segmentation

RFM analysis was used to understand customer purchasing behavior based on:

Recency – How recently a customer purchased
Frequency – How frequently a customer purchased
Monetary – How much revenue a customer generated

Customers were classified into the following segments:

Champions
Loyal Customers
New Customers
At Risk
Lost Customers
Potential Loyalists

This segmentation helps identify different customer groups and provides a structured way to analyze customer value and purchasing behavior.
